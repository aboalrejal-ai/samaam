# الجزء الأول — الاتجاه التصميمي

## ١.١ الموضوع، والجمهور، ووظيفة الشاشة الواحدة

**الموضوع:** بوابة برمجية تقف بين فنّي أشعة مُرهَق وجهاز أشعة مقطعية.

**الجمهور:** فنّي عند الشاشة في الساعة الثالثة فجراً، واستشاري يُستدعى ليقرر، ومحكّم يشاهد سبع دقائق فيديو.

**وظيفة الشاشة الرئيسية — واحدة فقط:**
> أن تجعل **الرفض** مفهوماً ومُبرَّراً في الثواني التي تسبق تعريض مريض للإشعاع.

ليست لوحة تحليلات. ليست بوابة مرضى. هي **لحظة رفض**، والتصميم كله يخدمها.

## ١.٢ العنصر المميِّز (Signature) — الصمّام

اسم المشروع **صِمَام**: الصمّام يفتح أو يُغلق مساراً. هذه ليست استعارة أضفناها، بل هوية المشروع.

المعيار ITU-T Y.3172 يفرض سبع عقد: `SRC → C → PP → M → P → D → SINK`.
ومطابقة هذه العقد **معيار تحكيم مستقل**.

**فاجمع الاثنين:** قضيب رأسي يمثّل العقد السبع، وبطاقة الطلب تتحرك عبره.
عند عقدة `P` إما تعبر، أو **يُغلق الصمّام** فتقف البطاقة بحدّ حادّ.

```
   SRC ●
    C  ●        بطاقة الطلب تنزل
    PP ●        عبر العقد
    M  ●
    P  ◉━━━━━━  ⬛ ← تقف هنا. حدّ صلب. لا تلاشي.
    D  ○
  SINK ○        باهتتان — لم تُبلَغا
```

هذا العنصر يخدم غرضين في آن: **جمالية لا تُنسى**، و**دليل مطابقة للمعيار** أمام لجنة التحكيم.

**المخاطرة الجمالية الوحيدة التي نأخذها هنا:** كل شيء في الواجهة هادئ وبطيء، إلا الإغلاق.
الإغلاق **فوري وميكانيكي** — 90 مللي ثانية، `cubic-bezier(0.2, 0, 0, 1)`، بلا ارتداد ولا تلاشٍ.
لا نافذة منبثقة ولا إشعار عابر. الجهاز يُغلق أمامك. هذا كل الجرأة التي ننفقها.

## ١.٣ الطباعة تحمل المعنى — ثلاثة أدوار

ليست الخطوط وعاءً محايداً. كل صنف من المحتوى له وجه، والقارئ يتعلّم النظام دون شرح:

| المحتوى | الخط | لماذا |
| :--- | :--- | :--- |
| **كل قيمة مقيسة** — `eGFR 27.7` · `DLP 900` · `120 mL` | `--font-mono` | هكذا تعرضها شاشات الأجهزة وتقارير المختبر. والأرقام الجدولية تتراصف عمودياً فتُقارَن بالنظر |
| **نص نظامي مقتبس** | `--font-body` + محاذاة يسار + خط عمودي على الحافة | مقتبس، لا مكتوب من عندنا |
| **الحكم** — `VIOLATION` | `--font-display` وزن ثقيل، تباعد أحرف موجب | كلمة واحدة تُقرأ من آخر القاعة |

**قاعدة صارمة:** أي رقم يمثّل قياساً يُكتب بـ `font-variant-numeric: tabular-nums`.
مقارنة `18.0` بـ `14.0` يجب أن تكون بصرية لا حسابية.

## ١.٤ اللون — لا نُنفق الدراما على الأزرق

اللوحة `#0ea5e9` سماوية، والخطر أن ينتهي الأمر إلى «لوحة تحكم طبية زرقاء» أخرى.

**فالأزرق ليس بطل الشاشة.** هو للتفاعل فقط: زر أساسي، تركيز، رابط. لا أكثر.
الدراما اللونية كلها محجوزة لتمييز واحد:

| السند | اللون | **الشكل** | النص |
| :--- | :--- | :--- | :--- |
| `STATUTORY` | `--danger` | شارة **ممتلئة**، زوايا حادة `4px` | مخالفة نظامية |
| `NATIONAL_PROTOCOL` | `--warn` | شارة **مفرَّغة**، إطار 1px، زوايا `999px` | خروج عن البروتوكول الوطني |
| `CLINICAL_GUIDANCE` | `--muted` | نص فقط، بلا خلفية | إرشاد مهني |

**اللون ليس القناة الوحيدة.** الشكل والزوايا يفرّقان أيضاً — فيقرؤها مصاب بعمى الألوان،
وتظهر على جهاز عرض رديء في قاعة التحكيم.

## ١.٥ ما نتجنّبه عمداً

- ✗ رقم ضخم وتحته تسمية صغيرة، وبطاقات إحصاء بتدرّج لوني — الجواب القالبي للوحات
- ✗ ترقيم زخرفي `01 / 02 / 03` — إلا على العقد السبع، حيث الترتيب **معلومة حقيقية**
- ✗ حركة على كل شيء. الحركة الوحيدة الحادّة هي الإغلاق
- ✗ زجاجية وظلال ملوّنة وتدرّجات على البطاقات
- ✗ أيقونات مبتسمة أو ودّية. هذا نظام يمنع ضرراً

# الجزء الأول-ب — ما هو هذا المنتج، وما ليس هو

## هذا ليس واجهة محادثة

دليل الهاكاثون يعدّ «بناء شات بوت عام وتسميته مشروع جاهزية» **الخطأ الشائع رقم ١**.

صمّام **بوابة تنفيذ** لا مساعد إجابات. الفنّي لا يكتب سؤالاً — يدخل إعدادات جهاز
ويضغط «إرسال إلى الجهاز»، فيرد النظام `200` أو `403`.

**الاستثناء الوحيد:** حقل بحث في صفحة قاعدة المعرفة. وهو **بحث دلالي لا محادثة**:
لا سياق متراكم، ولا دور مستخدم/مساعد، ولا توليد نص. يدخل استعلام، وتخرج سجلات
مرتّبة بدرجة التشابه. هذا ما يثبت للمحكّم أن الاسترجاع حيّ.

# الجزء الأول-د — اللغة والسمة

## اللغتان

| | القرار |
| :--- | :--- |
| الافتراضي | **الإنجليزية** — لجنة التحكيم دولية |
| المبدّل | عربي كامل مع `dir="rtl"` |
| التخزين | `localStorage` + `<html lang dir>` |

**المكتبة:** `i18next` + `react-i18next`. ملفان: `src/locales/en.json` و `ar.json`.

**RTL في Tailwind v4 — استخدم الخصائص المنطقية حصراً:**
```
ps-4 pe-4     بدل  pl-4 pr-4
ms-2 me-2     بدل  ml-2 mr-2
text-start    بدل  text-left
border-s      بدل  border-l
```

**لا يُترجَم أبداً:**
- النصوص النظامية المقتبسة — تُعرض بلغة مصدرها
- أسماء السجلات `MOH-CM-PROPHYLAXIS`
- أسماء الأحكام `VIOLATION` و `STATUTORY`
- القيم المقيسة ووحداتها

اقتباس بالإنجليزية داخل واجهة عربية يُعرض بـ `dir="ltr"` داخل الفقرة العربية.

## السمتان

| | القرار |
| :--- | :--- |
| الافتراضي | **فاتح** — أوضح في الفيديو، والحزمة مصمَّمة له |
| المبدّل | داكن عبر `.dark` على `<html>` |

الحزمة تعرّف السمة الفاتحة فقط. الوضع الداكن يعني **طبقة توكنز ثانية كاملة**
في `src/styles/dark.css` تعيد تعريف نفس أسماء المتغيّرات تحت `.dark`.

```css
.dark {
  --bg: #0b1220;  --surface: #131c2b;  --fg: #e8eef7;
  --fg-2: #b8c4d4; --muted: #8b9bb0;   --border: #24334a;
  --border-soft: #1a2536;
  --accent: #38bdf8;   /* يُفتَح للتباين على الداكن */
  --accent-on: #04131d;
  --success: #34d399;  --warn: #fbbf24;  --danger: #f87171;
}
```
ألوان الحالات تُفتَح على الداكن، وإلا سقط التباين. **افحص 4.5:1 في السمتين.**

**هذه المرحلة ٦٫٩ — آخر ما يُنفَّذ.** إن ضاق الوقت تُسقَط، والفاتح وحده يكفي للعرض.
